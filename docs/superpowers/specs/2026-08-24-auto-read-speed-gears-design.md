# 设计：自动阅读速度档位扩展

- 日期：2026-08-24
- 状态：已确认（用户批准方案A）

## 背景

小说阅读器自动阅读功能当前为 11 档速度（Slider 0–10，倍速公式 `0.5 + index × 0.15`，范围 0.5x~2.0x）。用户需求：**增加档位数量，最高速度翻倍到 4.0x**。

## 方案（已选定：方案A 线性 0.25 步进）

| 项 | 旧 | 新 |
|---|---|---|
| 倍速公式 | `0.5 + index × 0.15` | `0.5 + index × 0.25` |
| 滑块范围 | 0–10（11 档） | 0–14（15 档） |
| 速度范围 | 0.5x ~ 2.0x | 0.5x ~ **4.0x** |
| 默认档位 | index 5（=1.25x） | index **3**（=1.25x，默认手感不变） |
| 速度显示 | `toFixed(1)`（1.25 显示成 "1.3x"，错误） | 精确显示（"1.25x"，去尾零） |

新刻度全部为整齐的 1/4 步进：0.5 / 0.75 / 1.0 / … / 3.75 / 4.0。
