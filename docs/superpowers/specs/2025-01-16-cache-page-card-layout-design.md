# 缓存页面卡片化重构设计文档

## 概述

将"我的缓存小说"页面从单列列表布局重构为三列网格卡片布局，提升多作者场景下的浏览效率。

## 背景

当前 `CachedNovelsPage` 使用 `List` 组件以单列形式展示作者卡片。当缓存的作者数量增多时，用户需要大量滚动才能找到目标作者，阅读效率较低。

## 设计目标

1. **提升浏览效率**：三列网格布局，每行显示3个作者卡片
2. **保持信息完整**：保留作者分组、排序等核心功能
3. **优化交互体验**：长按删除替代按钮删除，卡片更整洁

## 布局设计

### 整体结构

```
┌────────────────────────────────────────┐
│  ‹ 我的缓存小说    ↕ 作者名    24      │
│  ────────────────────────────────────  │
│  12 位作者 · 48 本缓存                  │
├────────────────────────────────────────┤
│  ┌─────┐  ┌─────┐  ┌─────┐            │
│  │  A  │  │  B  │  │  C  │            │
│  │ 作者│  │ 作者│  │ 作者│            │
│  │ 5本 │  │ 3本 │  │ 8本 │            │
│  └─────┘  └─────┘  └─────┘            │
│  ┌─────┐  ┌─────┐  ┌─────┐            │
│  │  D  │  │  E  │  │  F  │            │
│  │ ... │  │ ... │  │ ... │            │
│  └─────┘  └─────┘  └─────┘            │
└────────────────────────────────────────┘
```

### 布局参数

- **列数**：3 列等宽
- **列间距**：10vp
- **行间距**：10vp
- **卡片内边距**：12vp
- **页面边距**：左右各 16vp

## 卡片设计

### 卡片内容（精简版）

```
┌─────────────────┐
│      ┌───┐      │
│      │ A │      │  ← 圆形头像（首字母）
│      └───┘      │
│    作者名称      │  ← 单行显示，超出省略
│      5 本       │  ← 小说总数
└─────────────────┘
```

### 卡片元素

| 元素 | 说明 |
|------|------|
| 头像 | 圆形，显示作者名首字母，46x46vp |
| 作者名 | 单行显示，`fontSize(14)`，超出省略 |
| 数量 | 显示 `X 本`，`fontSize(12)`，灰色 |

### 卡片样式

- 背景色：`$r('app.color.card_bg')`
- 圆角：12vp
- 阴影：`{ radius: 4, color: $r('app.color.card_shadow'), offsetY: 1 }`

## 交互设计

### 点击交互

- **点击卡片** → 进入作者详情页（保持现有逻辑）

### 长按交互

- **长按卡片** → 弹出上下文菜单
  - 删除选项：显示"删除作者缓存"
  - 取消选项：关闭菜单

### 删除确认

长按后弹出 `AlertDialog`，显示：
- 标题：删除作者缓存
- 内容：确定删除「作者名」的全部 X 本缓存吗？
- 按钮：取消 / 删除

## 技术实现

### 核心代码结构

```typescript
// 使用 Grid 替代 List
Grid() {
  ForEach(this.authorGroups, (ag: AuthorGroup) => {
    GridItem() {
      this.AuthorCard(ag)
    }
  }, (ag: AuthorGroup): string => ag.authorId)
}
.columnsTemplate('1fr 1fr 1fr')
.columnsGap(10)
.rowsGap(10)
.width('100%')
.layoutWeight(1)
.edgeEffect(EdgeEffect.Spring)
.padding({ left: 16, right: 16, top: 8, bottom: 16 })
```

### 长按手势

```typescript
@Builder
AuthorCard(ag: AuthorGroup) {
  Column() {
    // 卡片内容
  }
  .gesture(
    LongPressGesture()
      .onAction(() => {
        this.showDeleteConfirm(ag);
      })
  )
  .onClick(() => {
    this.openAuthorDetail(ag);
  })
}
```

### 删除确认对话框

```typescript
showDeleteConfirm(ag: AuthorGroup) {
  AlertDialog.show({
    title: '删除作者缓存',
    message: `确定删除「${ag.authorName}」的全部 ${ag.totalCount} 本缓存吗？`,
    autoCancel: true,
    primaryButton: {
      value: '取消',
      action: () => {}
    },
    secondaryButton: {
      value: '删除',
      fontColor: '#FF4D4F',
      action: async () => {
        // 执行删除逻辑
      }
    }
  });
}
```
